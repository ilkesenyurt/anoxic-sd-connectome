# FlyWire Death Simulation — Calibration Log

Sep 29, 2026 · @İlke Barış Şenyurt

## Overview

The model now has a stable healthy state and produces a spreading death wave after oxygen cutoff; timing and speed are not yet calibrated.

**Model.** A leaky integrate-and-fire (LIF) network on the FlyWire connectome (release 783), using Shiu et al. 2024 neuron parameters, plus a phenomenological "dying layer": per-neuron energy that decays after oxygen cutoff, rising resting potential (pump failure), depolarization block, cell-type vulnerability, and an extracellular K+ field that diffuses between spatial neighbours.

**Research question.** Does the fly brain's synaptic wiring shape how spreading depolarization travels, or is its path explained by physical geometry alone?

**Data.** `connections_princeton.csv`, `neurons.csv`, `coordinates.csv` (Codex marked neuron coordinates), `classification.csv`.

**Calibration targets (real fly data).**

| Target | Real value | Source |
| --- | --- | --- |
| Time to anoxic coma | \~30 s | Robertson lab (Drosophila anoxia) |
| SD wave speed | \~0.77 mm/min | Harris et al. 2026, iScience |
| Healthy extracellular K+ | \~3–4 (a.u. ≈ mM) | Hansen 1985 (mammal) |
| Pre-SD K+ ceiling | \~10–12 | Hansen 1985 (mammal) |
| K+ peak during SD | \~50–60 | Armstrong et al. 2011 (fly, \~54 mM) |

## Data loading fixes

Three bugs made early runs use fake data without any error; all are now found, two are fixed.

- **Coordinates silently replaced by random positions.** The code expected `x`, `y`, `z` columns, but the Codex file stores one text column, `position`, like `[352484 175164 229040]`. The `try/except` fallback hid the error. Fixed by splitting the text into three numbers.
- **Classes shown as "unknown".** `classification.csv` was not in the folder, so the fallback filled every neuron with "unknown". Fixed by adding the file.
- **Silent fallbacks still in the code.** Both `try/except` blocks in `load_data` remain. Not yet fixed: delete them so a missing file crashes loudly.

**Coordinate units are nanometres.** Every z is a multiple of 40 and every x a multiple of 4, matching FlyWire's 4×4×40 nm voxels; x spans \~700,000 nm ≈ 700 µm. Speed conversion: nm/ms × 0.06 = mm/min.

**Random subset replaced by a spatial box.** A random 3,000 neurons had almost no connections between them and "neighbours" that were far apart. The model now uses a cube centred on the median neuron position. A 100 µm cube (half = 50,000 nm) held only 329 neurons, because fly cell bodies sit on the brain's surface while the centre is neuropil. The current box uses half = 100,000 nm (a 200 µm cube): 12,256 neurons and 340,916 connections.

The healthy control is stable, and the death run shows healthy activity → rising firing → spreading silence, but it is \~3× too fast.

**Silencing order (death run, median block time):** optic 8.1 s → visual centrifugal 9.4 s → motor 10.0 s → endocrine 10.2 s → central 10.5 s → ascending 10.5 s → sensory ascending 10.6 s → descending 10.6 s → visual projection 11.0 s → sensory 11.3 s (absolute times; cutoff at 2 s). Optic neurons blocked first in three runs, but propagation is spatial-only, so this reflects location, not wiring.

**Caution on the surge.** In this model, depolarization raises firing before block by construction, so the rate increase is partly built in. The finding that would matter is a rise in *synchrony*, which the code records (`chi`) but has not yet been plotted.

**Known limitations**

- K+ is a phenomenological number, not real ion chemistry; no glia compartment, Ca2+, or neuromodulation.
- Each neuron is one marked point, usually near the cell body on the brain surface; real SD happens in the neuropil.
- Spatial diffusion treats all 8 neighbours equally regardless of distance.
- `D_K` is per timestep, so wave speed changes if `DT` changes.
- Blocking is permanent; a fly recovery experiment needs an unblock rule.
- Most dying-layer values are borrowed from mammals or guessed; fly coma is reversible, mammalian terminal SD is usually fatal.
- Calibration uses one measurement per target; the write-up must state which parameters were tuned to which data.
