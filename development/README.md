# Development history

Earlier model versions (`death_v2.py` … `death_v10.py`, `fast_sim*.py`) and the scripts that calibrated and tested them
(`stage2.py` … `stage15b.py`, validation scripts). They are kept so that the project log (`docs/project_log.md`) can be
followed version by version. They are **not** needed to reproduce the paper: everything in the paper comes from the
frozen model v11 and the scripts in `code/`.

Some of these scripts expect files or settings that later changed, so they may not run as they are.
